# AttentionX Prototype

## Problem
Long videos are hard to consume. Important moments are hidden.

## Solution
This tool allows users to upload a long video and automatically generates short clips.

## Features
- Upload video
- Automatically extract clips
- Save clips in temp folder

## How to run
1. Install dependencies:
   pip install fastapi uvicorn

2. Run server:
   python -m uvicorn main:app --reload

3. Open:
   http://127.0.0.1:8000/docs
