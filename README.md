## Demo

This is a working prototype of an automated content repurposing system.

Steps to run:
1. Start server using: uvicorn main:app --reload
2. Open: http://127.0.0.1:8000/docs
3. Upload a video
4. The system generates short clips automatically

Sample Output:
Clips are saved in /temp folder and can be played via browser.
